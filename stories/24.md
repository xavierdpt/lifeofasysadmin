# Thirty cylinders marked RESV

*Theme: Secrets handling*

The Amiga 3000 came up from the sub-basement on a trolley, along with a note from
Facilities saying the computing museum wanted it by the end of the month. It had run
the ion-beam stage in Materials until 2004 and had sat under a bench ever since.
Museum donations go through the same disposal review as anything else leaving the
building: the drive gets imaged, the image gets read, and nothing goes out of the
door until somebody has signed that there are no credentials on it.

Priya took the drive out — a 520 MB SCSI unit, still spinning — put it on a USB
adapter and pulled a full image with `dd`. That was the easy part. Reading it was
the part she had budgeted a morning for and got wrong.

An Amiga hard disk does not have an MBR. It has a Rigid Disk Block: a chain of
512-byte blocks in the first few sectors, each one tagged with a four-character id
— `RDSK`, `PART`, `FSHD`, `LSEG` — linked by block numbers and checksummed so the
longword sum comes to zero. Nothing in `fdisk`, `parted` or `lsblk` reads it. The
tool that does is `amiga-fdisk`, and in Debian and Ubuntu it ships three times from
one source package. `amiga-fdisk` and `amiga-fdisk-bf` are `Architecture: m68k
powerpc` — the machine you partition and the machine you partition *from* are
assumed to be the same machine. The third binary package is
`amiga-fdisk-cross`, in section `otherosfs`, `Architecture: linux-any`, described
in one line: *This is the version for non-Amiga systems.* Same source, same RDB
parsing, built for whatever the archive builds for. The author says in the README
that he wrote it on an Intel box and only tested it on his own A3000 afterwards,
and that it seemed to behave identically on little- and big-endian hosts. Without
that package, reading this image means finding a working Amiga — which is what the
museum wants, unmodified, at the end of the month.

```
$ sudo apt install amiga-fdisk-cross
$ amiga-fdisk -l /srv/disposal/a3000-materials.img
Disk /srv/disposal/a3000-materials.img: 16 heads, 63 sectors, 1010 cylinders, RDB: 0
Logical Cylinders from 2 to 1009, 516096  bytes/Cylinder 

   Device  Boot Mount   Begin      End     Size   Pri  BBlks    System
/srv/disposal/a3000-materials.img1    *    *         2      400   201096     0    2  Amiga FFS
/srv/disposal/a3000-materials.img2         *       401      979   291816     0    0  Amiga FFS Int.
/srv/disposal/a3000-materials.img3                 980     1009    15120     0    0  [unknown]
```

The device column is the string you passed with a number stuck on the end, which
looks silly against a file path and tells you the program was written for
`/dev/sda`. The `-l` flag is a listing: it never enters interactive mode, and it
reads one 512-byte sector at a time, reopening the file for each block, because it
was written to run inside a boot floppy with no swap. It found the `RDSK` block at
sector 0; it will search the first sixteen sectors, which is as far as the Amiga
standard lets the thing hide.

Two partitions where the paperwork said two partitions: DH0, the system disk, two
bootblocks; DH1, the data volume, 285 MB of scan logs. Priya read the third line
four times.

Thirty cylinders. 15 MB. No asterisk under Mount, no asterisk under Boot, and a
System column that said `[unknown]`.

The Mount column is printed from the partition block's flag word: an asterisk when
`PBFF_NOMOUNT` is clear, blank when it is set. The header in the source says what
the bit is for — *do not mount this partition (e.g. manually mounted, but space
reserved here)*. The README goes further and gives the recipe outright: set the
DosType to `RESV` and the flags to noboot, nomount, and the partition "will not
appear in the boot menu nor show up anyhow under Amiga OS". It exists because an
Amiga disk was normally shared. You kept AmigaDOS on one partition and something
else — Linux/m68k, a swap area, a raw region for VMM — on another, and the bit told
Workbench to leave the space alone instead of popping up a "Not a DOS disk"
requester at every boot.

`[unknown]` was the listing being unhelpful. `amiga-fdisk` formats the DosType
twice over: the hex value and the four characters in ASCII, then a name from a
lookup table. In list mode it skips the first part — the `if (!list_only)` guard
around the `sprintf` — and `RESV` has no entry in the table, so all that reaches
the screen is the fallback. Priya copied the image, ran the tool interactively on
the copy and pressed `p`:

```
/srv/disposal/copy.img3                 980     1009    15120     0    0  0x52455356 = RESV [unknown]
```

`0x52455356`. `R`, `E`, `S`, `V`. Somebody in 2001 had reserved the last thirty
cylinders of the ion-beam controller's disk and told AmigaOS not to look at it.
She quit with `q` rather than `w` and went at it with `dd` instead, using the
bytes-per-cylinder figure the listing had already printed for her: 980 cylinders in
at 1008 blocks each, 30240 blocks long.

```
$ dd if=a3000-materials.img of=resv.bin bs=512 skip=987840 count=30240
$ strings -n 6 resv.bin | grep -i -m5 'pass\|pwd\|login'
```

It was not a filesystem. It was a flat region somebody had been writing shell
notes into from a Linux/m68k install, and about 4 KB in there was a block of them
addressed to whoever came next: the DAT changer's SCSI id, the dial-up number for
the ion source vendor, and two lines giving a service account and its password in
the clear, for the departmental file server that had been decommissioned in 2009.

Priya would have stopped there and written it up as a historical credential, except
that the account name had a shape she recognised from a service account on the
current NAS — the same three-letter department prefix, the same `-svc` suffix. She
tried the password against it in a read-only bind. It authenticated.

The rotation went through at 14:20 that afternoon. The disposal ticket got the
`amiga-fdisk -l` output pasted into it, with the third line highlighted, and a note
that `resv.bin` and both images were to be destroyed once the museum had confirmed
receipt of the hardware. The museum got the drive with the RDB exactly as it was —
three partitions, thirty cylinders of them still marked RESV.
